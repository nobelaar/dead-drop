# Characters

Character sheets for **DEAD DROP**.

One file per character (or per major role). A character entry can include biography, personality, relationships, secrets, and implementation notes (what exists in-game vs. lore-only).

## How to use

- Name files after the character: `slug.md` (e.g. `nicolas-ferreyra.md`).
- Start from [`_template.md`](_template.md); do not invent TBD fields.
- Keep spoilers and secrets in a clearly marked section.
- Link to story docs when a beat depends on someone.
- **Language:** English (project narrative docs).
- Agents: follow `.agents/skills/dead-drop-narrative-docs/SKILL.md`.
- Sheets are **living documents**. Casual canon (“Nico plays guitar”) must be written into the right file proactively.
