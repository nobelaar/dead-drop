# Story

Narrative source of truth for **DEAD DROP**.

Documents here describe plot, locations, factions, and beats.  
They are **not** loaded by the game at runtime unless we later wire a specific file into a scene.

## How to use

- Write and revise story here first.
- Implement only what the current milestone needs.
- Keep terminal dump text (`data/terminal_message.txt`) in sync when a beat is playable.
- Agents: follow `.agents/skills/dead-drop-narrative-docs/SKILL.md` for structure, edits, and canon safety.
- These docs are **living**: any new user-stated lore should be filed here (or under `characters/`) without waiting for an explicit “update the docs” request.

## Index

| File | Purpose |
|------|---------|
| [overview.md](overview.md) | Logline, tone, current known facts |
| [timeline.md](timeline.md) | Ordered events (in-world and playable) |
| [locations.md](locations.md) | Places the player can or will visit |

Add new files as arcs grow (acts, quests, endings). Do not delete history; mark superseded notes clearly.
